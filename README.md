# PaKuFamily

Strona główna rodziny PaKu: wszystkie aplikacje w jednym miejscu, z opisami, kodami QR i linkami (8 języków).

- `index.html` – strona
- `family.js` – wspólna lista aplikacji (ten sam plik jest w każdej aplikacji PaKu)
- `family.json` – lista aplikacji, z której zainstalowane aplikacje dowiadują się o nowych członkach rodziny
- `qr.svg` (ta strona), `qr-paku.svg`, `qr-grounding.svg`, `qr-steps.svg`, `qr-honicorn.svg`, `qr-word.svg` – kody QR
- `icon.svg`, `icon-192.png` – ikona

Nowa aplikacja w rodzinie: dopisz ją w `family.js` i `family.json`, dodaj kod QR.

Adres: `https://zondelekpp-wq.github.io/PaKuFamily/`
